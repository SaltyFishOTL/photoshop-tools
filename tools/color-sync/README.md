# Color Sync 0.7.1

Photoshop 相似图层配色与渐变同步。安装和使用参见[项目主页](../../README.md)。

`ColorSync.psjs` 包含配色算法、图层操作和紧凑双栏界面；`ColorSync.jsx` 注册滤镜菜单；`Launcher.cs` 通过 COM 将菜单调用转到实际脚本，连接已有 Photoshop 实例。

在 Windows PowerShell 中构建辅助程序：

```powershell
& "$env:WINDIR\Microsoft.NET\Framework64\v4.0.30319\csc.exe" /nologo /target:winexe /platform:x64 /reference:System.Windows.Forms.dll /reference:System.Web.Extensions.dll /out:ColorSyncLauncher.exe Launcher.cs
```

将生成的 EXE、两个脚本和 Install.ps1 放在同一个文件夹，即可按主页步骤安装。

配色算法对平坦色样本建立颜色分组，拟合二维渐变场，应用平滑的颜色差值；不是逐像素覆盖。0.4.1 仅调整界面，配色算法保持原效果。

## 0.7.1 西装局部色差与镜片层次修复

修复 0.7.0 将镜片亮暗变化当作色差抵消的问题，同时加强同一材质在不同位置的色差修正。使用方式不变：选择参考层，勾选需要同步的原始目标层。若已经生成 0.7.0 的结果，请重新选择原始目标层处理；在旧结果上叠加无法找回被压缩的反光层次。

- 去掉依赖目标像素 RGB 的回归项，只拟合随位置变化的颜色差值。扩大初始化颜色分组的间隔，减少同一材质的相近明暗被过度拆分。
- 在二维渐变场之外，以附近样本的稳健加权估计细化局部修正，避免左袖、右袖、肩部等不同位置的偏色被整件衣服的统计平均掉。样本不足时使用原有空间拟合。
- 对修正量进行颜色约束的平滑，再叠加回原图；不模糊原图、不复制参考层的线条或表情。平滑半径随图像尺寸变化，为 2–12 像素。黑线、白色背景和完全透明像素不参与平滑，也不写入。
- 仍保留单次每通道最多 40 的修正范围、输出副本、可编辑像素蒙版和一个撤销步骤。平滑阶段可取消。

这仍是相似图层的局部颜色估计，不是语义识别。很近的材质边界、改变位置的高光及表情仍可能存在残余差异，不能保证对应区域所有像素 RGB 完全一致。原图渐变和细节优先保留。

验证：`node test-convergence.js` 检查灰色材质、高光、位移、渐变、同图不变、Alpha/黑线保持及重复处理；`node test-detail-preservation.js` 专门检查同一材质的左右局部偏色、错位镜片反光及各阶段取消。新增构造测试中，旧 0.7.0 的镜片相邻像素明暗差保留率约 68%，0.7.1 约 100%；左右衣袖的平均通道误差由 8 和 6 降至 0。构造测试数字不代表任意实图。用户三张实图以第三张为参考，仅在本地比较肩部、袖口和镜片，图片不加入仓库或安装包。

`node build-mask-test.js` 生成独立临时文档的 Photoshop 验证脚本，用于检查柔边、硬边、停用蒙版、无蒙版、参考层保持及失败回滚。

## 0.7.0 相似帧的区域配色统一（历史版本，已被 0.7.1 修正）

针对同一角色的轻微抖动、眨眼或表情变化。选择一层作为参考，在右侧勾选其余目标层，点击“同步配色”。仍生成目标副本并保留参考层；不改变目标图层的几何位置、透明度或可编辑像素蒙版。

新版在相近位置寻找对应的平滑色块，分别估计底色、高光、暗部的颜色变化。颜色分组从最多 8 组增至最多 32 组，接近灰色的夹克和高光也参与同步。根据对应色样同时拟合颜色变化和二维渐变，在相邻颜色分组之间连续混合，减少硬分组造成的色带。一次拟合直接输出，不再依靠三次整体颜色修正。

匹配使用排除黑线、白色背景和明显边缘后的样本；按有效图像范围归一化坐标，只在附近约 3.5% 的范围内寻找候选。这个搜索仅用于学习颜色，不会移动或复制参考层的线条和表情。单次每通道修正最多 40，黑线、接近纯白背景、完全透明像素受保护。低置信度颜色渐弱处理。

适用范围是颜色略有偏差且内容高度相似的图层；不保证不同姿势、大幅位移、不同材质或极小高光自动对应，也不保证真实画面所有 RGB 像素逐点相等。每种材质的颜色一致与整幅图像完全相同是不同目标。

验证：`node test-convergence.js` 覆盖轻微位移、灰色夹克、灰色高光、肤色和衣服的独立色偏、渐变变化、重复处理稳定性、同图不变、黑线和 Alpha 保持、取消。构造测试中色块平均通道误差由约 4–12 降至 0–0.013；这些数字不代表任意真实图片。`node build-mask-test.js` 的 Photoshop 真机测试继续覆盖柔边、硬边、停用蒙版、无蒙版、参考层保持、临时层清理及失败回滚。用户图片仅用于本地检查，不随源码或安装包发布。

本机 PS 26.8 已验证菜单调用、辅助进程退出、临时文档双目标输出与算法结果一致、参考层及透明度不变。0.4.1 的实际 PS 布局验证确认每行 25 像素、列表 392 像素，底部按钮完整可见。


## 0.5.0 蒙版支持

普通像素蒙版在临时副本上应用，原图层和输出副本的可编辑蒙版保留；只将计算后的 RGB 回写，原始 Alpha 不变。完全隐藏的像素保持原样，停用蒙版按未应用处理。矢量蒙版与图层效果仍不支持。

运行 node build-mask-test.js 生成 release/mask-validation.psjs，通过 Photoshop 执行该脚本可在独立临时文档中验证：带蒙版参考层、柔边/未羽化/停用蒙版目标、无蒙版目标、蒙版像素与属性保持、原始 Alpha 保持、取消回滚和完全遮挡回滚。报告输出 release/mask-validation.json；测试不会写入已有 PSD。


## 0.6.0 单次点击内细化

一次点击最多执行三轮原有颜色场修正，像素不再变化时提前结束。参考分析复用，后续轮次在内存中重新拟合目标；只创建一个结果层，保留同一个撤销步骤。每轮仍保留 24/通道的修正上限及黑线、白色、低饱和保护，累计变化可能更大；不能保证任意图像一次完全一致。单次计算量可能增加，但省去重复读取、写回和手工操作。蒙版只应用一次用于读取，输出继续保留原 Alpha 和可编辑蒙版。
